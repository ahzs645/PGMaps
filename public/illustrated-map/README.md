# Reference for the illustrated map workshop

`page8-reference.jpg` is the exact embedded map raster from page 8 of the user-supplied
Destination BC *Rainforest to Rockies Industry Brand Guidelines* (1536 by 945 pixels).
It is shown only as the labelled reference in `/dev/illustrated-map` and its offline
review export. It is not used as input by the vector drawing or hatching generators.

Public document: https://www.destinationbc.ca/content/uploads/2024/03/Rainforest-to-Rockies-Industry-Brand-Guidelines.pdf

The original map and identity are Destination BC material. The constructed SVGs are
identified as reconstructions, not original source artwork. Their implementation,
scope, construction methods and research are in `docs/illustrated-map-reconstruction.md`.
