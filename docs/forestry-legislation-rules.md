# Forestry legislation rules catalogue

For the proposed JSON schemas, official CiviX XML ingestion, 2004 Prince George
biodiversity-order tables, GoRules ZEN JDM sample, json-rules-engine sample, and
OpenFisca-inspired historical parameter design, see
[packages/legal-rules/README.md](../packages/legal-rules/README.md).

This is **draft advisory work**, not a PGMaps legal compliance certificate and is
not yet connected to live route planning. Before showing regulatory findings,
a local legal-order overlay and applicable approvals must be verified for the
specific cutblock date, footprint, tenure and geographic scope.
