The adaptation translates the daily arithmetic, supplies strict chronological
input validation, explicit summary policies, deterministic year-selection
helpers, custom anomaly inputs and exports. It preserves original attribution
and documents behavior differences in docs/forest-drought-model.md. Scientific
scope and comparison evidence are distinct from software licensing. The host
repository's MIT licence does not replace this Apache-2.0 licence.
